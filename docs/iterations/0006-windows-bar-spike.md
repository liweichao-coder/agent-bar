# Iteration 0006: Windows Bar Spike

状态：Partially verified; multi-monitor and recovery matrix pending

## 目标

验证 Tauri 2 是否能支撑第一代桌面常驻状态条的核心窗口行为，而不是只在浏览器中模拟一条顶部导航。

## 本轮完成

- 增加 `expanded` 与 `compact` 原生窗口模式。
- compact 模式使用当前显示器完整逻辑宽度和 68px 客户区高度。
- compact 模式关闭装饰、阴影和缩放，启用 always-on-top 并贴到显示器顶边。
- expanded 模式恢复装饰、缩放、最小尺寸和普通层级，并居中显示。
- React 顶部状态条提供紧凑/展开切换入口；浏览器模式保留同样的布局演示。
- 增加点击穿透 Tauri 命令和隔离测试启动开关，但未在正式 UI 中开放。

## Windows 实机证据

验证环境：1920×1080，100% DPI，Tauri 2.11.5。

- compact 外框：左上角 `(0, 0)`，尺寸 `1920×68`。
- compact 客户区：左上角 `(0, 0)`，尺寸 `1920×68`。
- `WS_EX_TOPMOST` 为真，进程处于响应状态。
- 点击穿透隔离启动时 `WS_EX_TRANSPARENT` 为真。
- 浏览器布局检查中状态条高度为 68px，主工作台隐藏，无水平溢出；展开后工作台恢复。

Windows 在无边框窗口外仍可能保留 DWM 不可见边框。实现读取 outer/inner position 的差值，重新定位外框，使实际客户区从屏幕 `(0, 0)` 开始。

## 尚未通过的门槛

- 多显示器和负坐标显示器。
- 125%、150% 和混合 DPI。
- Windows 任务栏位于顶部、侧边或自动隐藏。
- 睡眠、唤醒、显示器热插拔和分辨率改变后的恢复。
- 全局快捷键恢复入口；托盘恢复入口已在 Iteration 0007 完成。
- 紧凑状态条自动避让全屏应用的策略。

## 决策

当前证据支持继续使用 Tauri，不足以完成 Tauri/Electron 最终决策。托盘恢复已经完成，但点击穿透仍需等全局快捷键或更明确的首次使用确认后再开放到正式界面。
